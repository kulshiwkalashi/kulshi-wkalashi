# كلشي وكلاشي — MVP

نسخة أولية متجاوبة باللغة العربية وباتجاه RTL لسوق إعلانات مبوبة عراقي.

## التشغيل

هذه النسخة لا تحتاج Node أو قاعدة بيانات لتجربتها. افتح `index.html` مباشرة في المتصفح، أو شغّل خادمًا محليًا:

```bash
python3 -m http.server 4173
```

ثم افتح `http://localhost:4173`.

## ما يعمل الآن
- الصفحة الرئيسية وهوية «كلشي وكلاشي».
- أقسام: العقارات، السيارات، السلع، الوظائف، الخدمات، الحيوانات، متنوع.
- بحث بالكلمات المفتاحية.
- فلاتر للقسم والمحافظة والحالة والترتيب بالسعر.
- صفحات تفاصيل الإعلان ومعرض الصور.
- اتصال، مراسلة تجريبية، مشاركة، مفضلة، وإبلاغ.
- تسجيل دخول/حساب تجريبي محفوظ محليًا.
- إضافة وحذف الإعلانات.
- إعلاناتي والمفضلة والرسائل.
- لوحة تحكم أولية للمشرف.
- بيانات عراقية تجريبية.
- تصميم responsive للموبايل والكمبيوتر.

## ملاحظة هندسية
لتحويل MVP إلى منتج حقيقي، يُفضّل نقل البيانات من `localStorage` إلى PostgreSQL عبر Supabase أو Backend مخصص، وإضافة Auth حقيقي، تخزين صور، نظام صلاحيات، رسائل لحظية، مكافحة الاحتيال، سجل تدقيق، وخدمة إشعارات.

## بنية التوسع المقترحة
- Frontend: React/Next.js أو هذا الـSPA كمرحلة إثبات مفهوم.
- Backend/DB: PostgreSQL + Supabase أو Node.js/NestJS.
- Storage: S3-compatible object storage.
- Mobile لاحقًا: React Native أو Flutter مع API مشترك.
- Payments لاحقًا: طبقة دفع منفصلة للإعلانات المميزة والاشتراكات.
